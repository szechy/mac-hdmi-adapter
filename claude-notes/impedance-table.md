On 2026-10-19 an impedance control table was added to `mac-vintage-hdmi.kicad_pcb` for the fab. It is a native KiCad table plus a title and notes, all in the group "Impedance table", on **User.3**. That layer was renamed "Impedance" and sits below the board at y ≈ 68–110 mm. It is 162 mm wide, wider than the board.

- **Export:** the layer is in the board's plot layer selection, so it plots as `mac-vintage-hdmi-Impedance.gbr`. `fabrication-toolkit-options.json` has `EXTRA_LAYERS = "User.3"`. Avoid User.1/User.2: the Fabrication Toolkit uses them for V-cuts and an alternate board edge.
- **Format:** the columns follow `datasheets/Required_impedance_control.xlsx`, which is JLC's form: Signal Layer | Reference Layer | Impedance Type | Trace Width (mil) | Trace Spacing (mil) | Impedance (ohm) ±10% | Position. In the xlsx, Position is a screenshot. On the board it is text naming the nets and the parts they run between.
- **Profiles:** at the user's request, the In2.Cu entry was removed from the USB_90R tuning profile and the In1.Cu entry from 50_SE. Neither layer had any of those nets routed. The four remaining rows are HDMI L1/L2, USB L1/L2, 50_SE L1/L2 and 50_SE L4/L3.
- **Coplanar labels:** these are a judgment call; the profiles don't say. The GND pour stops 0.3 mm from the traces, and the L1–L2 dielectric is 0.21 mm. A row is labelled coplanar if most of its length has pour within 0.35 mm of the trace edge:
  - USB L1: 89%, coplanar.
  - 50_SE L4: 60%, coplanar.
  - HDMI: 39%, non coplanar.
  - 50_SE L1: 25%, non coplanar.
- **Open issue:** 50_SE is 0.30 mm in the profile, but a field solve gives ≈54–55 Ω at that width (0.35 mm ≈ 50 Ω). Its B.Cu segments are also routed at 0.20 mm.
- **Script:** the table was generated by `mac-vintage-hdmi/scripts/impedance_table.py`, kept as a reference only. The user said not to bother making it re-runnable. Usage: `<in.kicad_pcb> <kicad_pro> <out.kicad_pcb>`. It assumes no table is already present, and it must be run with KiCad's Python. Loading a second board in the same process returns an unwrapped SwigPyObject.
- **KiCad 10 table syntax:** pcbnew's SWIG bindings don't expose `PCB_TABLECELL`. To build a table, write the s-expression (`(table (column_count N) … (cells (table_cell "txt" (start) (end) (margins) (span 1 1) (layer) (effects …)) …))`), then LoadBoard + SaveBoard to validate it and normalise the formatting. A LoadBoard/SaveBoard round-trip doesn't change anything else in this board.
