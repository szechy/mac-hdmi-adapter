# Project notes

Claude's notes for this project live in `claude-notes/` and are versioned with the repo. The index:

@claude-notes/MEMORY.md

Each line links to one note file in `claude-notes/`. Read the ones relevant to the task before starting. They record part choices, verified pinouts, layout review findings and recipes that aren't obvious from the KiCad files. Notes reflect the state when they were written, and the board changes often, so re-check the KiCad files before quoting a note as current.

Save new or updated notes in `claude-notes/`, not in Claude's per-user memory directory. Use one fact per file with the same frontmatter as the existing notes. Add a one-line pointer to `claude-notes/MEMORY.md`. Update an existing note rather than duplicating it.
